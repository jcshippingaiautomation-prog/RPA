## PROMPT ที่ส่งให้ Claude

```
ช่วยสร้างคู่มือการใช้งานเป็นไฟล์ Canva presentation (อัตราส่วน 16:9) ให้หน่อย
เป็นคู่มือ "ระบบ RPA Import DCTK (DCTK Automation)" — ระบบช่วยพนักงานชิปปิ้งสร้างใบขนสินค้าขาออกในระบบกรมศุลกากร (DCTK) อัตโนมัติด้วย AI + RPA

กลุ่มเป้าหมาย: พนักงานชิปปิ้ง (ผู้ใช้ทั่วไป) และผู้ดูแลระบบ (admin)
ภาษา: ไทย
สไตล์: สะอาด มืออาชีพ โทนน้ำเงินเข้ม (#1f2a44) + ขาว ใช้ฟอนต์อ่านง่าย (Noto Sans Thai หรือใกล้เคียง)
สำคัญ: ทำให้ทุก element เป็นวัตถุที่ผมแก้ไข/ย้าย/เปลี่ยนข้อความเองได้ใน Canva (ไม่ flatten เป็นรูปเดียว) — ผมจะแก้ต่อเอง

ขอ ~16 สไลด์ ตามโครงนี้ (ผมแนบภาพหน้าจอจริง 11 ภาพมาให้ใช้ประกอบ ชื่อไฟล์ตามวงเล็บ):

1. สไลด์ปก — ชื่อ "คู่มือการใช้งาน DCTK Automation" + ซับ "ระบบสร้างใบขนสินค้าขาออกอัตโนมัติ ด้วย AI + RPA" + โลโก้/ไอคอนกล่อง

2. ภาพรวมระบบ — flow แนวนอน 1 บรรทัด: "อัปโหลด/ดึงอีเมล → AI สกัดข้อมูล → ตรวจ/แก้ → กดรัน → RPA กรอก DCTK → ได้ PDF ใบขน" (ทำเป็น diagram ลูกศร)

3. ผู้ใช้ 2 ระดับ — เปรียบเทียบ admin (เข้าทุกอย่าง+ตั้งค่า) vs ผู้ใช้ทั่วไป (ใช้งาน ไม่เห็นตั้งค่า) แบบ 2 คอลัมน์

4. เข้าสู่ระบบ (Login) — ใช้ภาพ [01-login.png] + อธิบาย: กรอกอีเมล+รหัสผ่าน → เข้าสู่ระบบ

5. หน้าหลัก "รายการใบขน" — ใช้ภาพ [02-list.png] + ชี้ส่วนสำคัญ: การ์ดสถิติ(ทั้งหมด/พร้อมรัน/เสร็จ), ตัวกรอง, ปุ่มเครื่องมือ(ดึงอีเมล/อัปโหลด/สร้าง), ตาราง

6. ความหมายสถานะ — ตารางสี: พร้อมรัน(ฟ้า)/รอคิว+กำลังรัน(เหลือง)/เสร็จ·สร้างแล้ว(เขียว)/แก้แล้ว(ส้ม)/ผิดพลาด(แดง คลิกดูสาเหตุได้)

7. วิธีที่ 1: อัปโหลดไฟล์ให้ AI สกัด — ใช้ภาพ [03-modal-upload.png] + ขั้นตอน: เลือกลูกค้า → ลากไฟล์(PDF/รูป/Excel/Word) → กดประมวลผล → AI สกัดเป็นรายการ

8. วิธีที่ 2: สร้างรายการเอง — ใช้ภาพ [04-modal-create.png] + กรอกข้อมูล 25 ช่องเอง

9. วิธีที่ 3: ดึงอีเมลอัตโนมัติ — ใช้ภาพ [05-modal-poll.png] + ดึงเอกสารจาก Gmail (ผู้ส่งใน allowlist)

10. ตรวจ/แก้ข้อมูลก่อนรัน — ใช้ภาพ [06-modal-detail.png] + อธิบาย: ดูสถานะ, แก้ฟอร์มข้อมูล, ตารางรายการสินค้า, เอกสารแนบ, ปุ่ม "รัน RPA"

11. การรัน RPA + ดูผล — อธิบาย: กดปุ่ม "รัน" → ระบบเปิด DCTK กรอกอัตโนมัติ → เห็น log สด → เสร็จได้ PDF → กด "ดูไฟล์" เปิด PDF ใบขน

12. ประวัติงาน — ใช้ภาพ [07-history.png] + ดูประวัติการรัน + คลิกแถวดู log เต็ม/สาเหตุที่ไม่สำเร็จ

13. [ADMIN] ตั้งค่า: อีเมล — ใช้ภาพ [08-settings-email.png] + Allowlist อีเมลผู้ส่งที่อนุญาต

14. [ADMIN] ตั้งค่า: AI & RPA — ใช้ภาพ [09-settings-airpa.png] + เลือกโมเดล AI + ตั้งค่าเชื่อม DCTK

15. [ADMIN] ตั้งค่า: ลูกค้า — ใช้ภาพ [10-settings-customer.png] + ให้ AI ร่างกฎการสกัดต่อลูกค้า + Field Rules (กำหนดแต่ละช่อง)

16. [ADMIN] ตั้งค่า: ผู้ใช้ + สรุป — ใช้ภาพ [11-settings-users.png] + สร้าง/จัดการผู้ใช้ + สรุปขั้นตอนใช้งานสั้นๆ

แต่ละสไลด์: หัวข้อใหญ่ชัดด้านบน + ภาพหน้าจอ(ถ้ามี)ด้านหนึ่ง + คำอธิบายเป็น bullet สั้นๆ อีกด้าน
สไลด์ admin (13-16) ใส่ป้าย "สำหรับผู้ดูแลระบบ" มุมบนให้แตกต่าง
ทำ template สม่ำเสมอทุกสไลด์ (หัว/ท้าย/สีเดียวกัน) เพื่อให้ดูเป็นชุดเดียวกัน
```
